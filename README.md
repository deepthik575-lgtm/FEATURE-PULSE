# FeaturePulse — AI-Driven Feedback Analytics

An AI-powered feedback analytics system that replaces traditional keyword searches by using semantic similarity to uncover hidden bug clusters and feature gaps.

## Features
- Semantic similarity search using vector embeddings
- Automated bug and feature-request clustering
- Interactive Streamlit dashboard for real-time customer sentiment tracking

## Tech Stack
- Python
- ChromaDB
- Sentence Transformers
- Streamlit
